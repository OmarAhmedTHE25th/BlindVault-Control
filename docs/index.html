How Connections Establish

Four Ephemeral Steps From Discovery to Encrypted Stream

Every handshake, invite code, NAT reflection probe, and fallback tunnel is stateless on disk and bound by automatic Redis TTLs.

Replay-Proof Handshake SECP256R1 Strictly Enforced

Prove Identity Without Sending Private Keys

The peer submits its PEM/DER public key in HELLO. Only secp256r1 keys pass curve validation to derive the lowercase SHA-256 fingerprint, then the server stores a 32-byte nonce in Redis consumed once via GETDEL.

Human-Safe Out-of-Band Invites

Peers exchange a short 8-character Crockford Base32 code (excluding ambiguous I, L, O, U characters). Claiming atomically deletes the invite via GETDEL, blocks self-pairing, and delivers mutual PEER_MATCHED messages containing only client-declared endpoints.

Cryptographically Signed Endpoint Reflection

Instead of unsigned STUN packets, a 20-byte "BVST" probe returns a 99-byte (IPv4) or 111-byte (IPv6) packet signed by the server's Ed25519 key (published via GET /api/v1/info), preventing address spoofing before SIGNAL_OFFER, SIGNAL_ANSWER, and HOLE_PUNCH_SYNC.

[4:20] Nonce 16B Echo
[20] 4 | 6 1B Fam
[21:+L] IP 4B / 16B
[+2] Port uint16 !H
[+8] Epoch uint64 !Q
[+64] Ed25519 Sig 64B Auth

Production & Local Setup

Deploy With Docker Compose or Run Locally

Includes an ephemeral RAM-only Redis 7 container, FastAPI control/relay ports (:8000 TCP), and UDP endpoint reflection (:3478 UDP). 

# 1. Clone and boot Redis 7 (RAM-only: --appendonly no --save "") + blindvault-control
git clone https://github.com/OmarAhmedTHE25th/blindvault-control.git
cd blindvault-control
docker compose up --build

# 2. Verify liveness, readiness, and Ed25519 UDP public key discovery
curl -s http://localhost:8000/health | jq
curl -s http://localhost:8000/ready | jq
curl -s http://localhost:8000/api/v1/info | jq

# Exposed Services:
# - Control & Relay WebSockets: ws://localhost:8000/ws/control & /ws/relay/{session_id}
# - Signed UDP Reflector:       udp://localhost:3478 (Magic: BVST / 0x42565354)
# 1. Create virtual env and install runtime + dev dependencies (Python 3.12+)
pip install -e ".[dev]"

# 2. Run 41/41 hermetic tests (fakeredis[lua]) + strict typing + linting
pytest -v
mypy src/
ruff check .
ruff format --check .

# 3. Start FastAPI + UDP reflector locally & run performance benchmarks
blindvault-control
python benchmarks/bench_control.py
# Core Bindings & Production Signing Key
